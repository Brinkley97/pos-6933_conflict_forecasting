
# Conflict Forecasting Democracy Example

This folder is designed to show students how to move from selecting a theory to producing a complete forecasting memo.

## Getting Started

1. Read `01_Model_Development.pdf` for the assignment overview and requirements.
2. Read `02_Modeling_Guide.pdf` for guidance on how to build a theory-driven forecasting model.
3. Run `code/model_building_tutorial.R` to estimate the democracy model and generate results.
4. Review the outputs in `results/democracy_model/`.

## Folder Structure

* `data/` — main imputed modeling dataset.
* `codebooks/` — codebooks and source documentation for key variable families.
* `benchmark_results/` — benchmark prediction files, tuning tables, and benchmark plots.
* `code/` — R code for the worked democracy example.
* `results/` — generated model outputs, tables, and plots.
* `output/pdf/` — polished PDF deliverables.

## Main Files

* `01_Model_Development.pdf` — assignment overview and expectations.
* `02_Modeling_Guide.pdf` — guide for developing a theory-driven model.
* `03_Democracy_Model_Memo.pdf` — sample memo illustrating how results can be organized and presented.
